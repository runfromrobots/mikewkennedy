About This Map

This interactive map displays three key data layers for Root Arboretum:

  • Trail Route: The 1.5-mile main loop trail (green line) providing access through the property
  • Property Boundaries: The 200-acre main property and adjacent parcels that comprise Root Arboretum
  • Plant Observations: Documented plant species observations from our growing collection, recorded via iNaturalist and automatically synced to this database

Use the layer controls to toggle different data on and off. The map supports zooming, panning, and clicking on observations to see full details.

Root Arboretum preserves, cultivates, and interprets native and heritage trees on a historically significant landscape in the Mohawk Valley.
